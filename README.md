# Yash Dhame — Portfolio

A modern, responsive personal portfolio website showcasing my projects, technical skills, experience, education, and development journey.


Live demo : https://yash-dhame-portfolio.vercel.app/
## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Minimal and modern UI
- Featured project showcase
- Alternating split-screen project layout
- Project screenshots with GitHub and Live Demo links
- Skills and technology overview
- Experience and education sections
- DSA / problem-solving section
- Contact form
- Social media links
- Resume access
- Smooth animations and interactions
